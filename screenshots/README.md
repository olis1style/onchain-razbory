# Скриншоты-доказательства

Сюда кидаешь **оригинальные** скриншоты (Arkham, DexScreener, Etherscan) — как есть,
без обработки. Я из них делаю размеченные версии и вставляю в разбор.

## Как называть

```
<разбор>-<что-на-скрине>.png
```

Например: `gonka-dexscreener.png`, `gonka-arkham-hub.png`, `gonka-holders.png`

## Что происходит дальше

- `*-raw.png` — оригинал, как ты прислал (можно и без суффикса)
- `*-annotated.png` — версия с разметкой: рамки вокруг важного, стрелки, подписи прямо
  на картинке. Делаю я, вручную/скриптом.
- В HTML вставляется только размеченная версия, внутри `<figure>` с подписью.

## Что полезно скринить

| Что | Зачем |
|---|---|
| Страница кошелька в Arkham (метки, баланс) | доказать теги и суммы |
| Вкладка Transfers / первый спонсор | доказать связь кошельков между собой |
| Топ-холдеры токена | доказать долю в процентах |
| График DexScreener с окном сделок | показать момент и объём покупки |
| Портфель кошелька (что ещё держит) | показать тематику ставок |

Скрины лучше делать во всю ширину окна и в тёмной теме — под стиль сайта.
