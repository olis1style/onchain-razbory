# onchain разборы

Статический сайт с мини-расследованиями по блокчейну. Публикуется через GitHub Pages
на домене **onsurge.tech** (файл `CNAME` в корне трогать нельзя — он держит привязку домена).
**Никак не связан с репозиторием портфолио** — отдельный репозиторий, отдельные файлы.

## Структура

```
index.html          главная — список всех разборов
assets/style.css    общий стиль для всех страниц
gonka/index.html    разбор №1 — Wrapped Gonka
screenshots/        оригиналы и размеченные скриншоты (см. README внутри)
```

## Как добавить новый разбор

1. Скопировать папку последнего разбора → переименовать (`gonka` → `новое-имя`).
2. Заменить содержимое, обновить `<title>`, `<meta description>` и og-теги.
3. Добавить карточку в `index.html` в блок `.card-list` — новые сверху.
4. Скриншоты положить в `screenshots/`, вставить через `<figure>`.
5. Закоммитить и запушить — Pages пересоберётся сам за минуту.

```bash
git add -A && git commit -m "разбор: <название>" && git push
```

## Локальный просмотр

```bash
python3 -m http.server 8000
```

## Правила текста

- Пишем так, чтобы понял человек без крипто-опыта. Термин ввёл — сразу объяснил.
- Никаких «сухой порох», «набирает лонг», «памп». Вместо этого: «деньги лежат нетронутыми»,
  «набирает позицию», «резкий рост».
- Факт и догадка всегда разделены явно. Метки Arkham от нейросети помечаем как догадки.
- В конце каждого разбора — три сценария с оценочными вероятностями и признаком,
  по которому видно, какой из них реализуется.
- Все адреса приводим полностью, чтобы читатель мог проверить сам.
